# 06 — 执行结构化命令回退限制并收敛工具提示

**What to build:** 让运行时 Harness 根据专用方块工具的结构化结果决定是否允许命令回退，并让 MCBE Chat Agent 只看到编辑组编排所需的简短、一致规则。

**Blocked by:** 01 — 恢复现有方块编辑的可信结果语义; 04 — 扩展为一次审批的独立编辑组.

**Status:** ready-for-agent

- [ ] 当前连接确认支持专用方块能力后，最近一次同任务专用方块失败为 `fallback_allowed=false` 时，拒绝 `setblock`、`fill` 和 `clone` 命令回退。
- [ ] 回退状态按连接、当前事件 `player_name` 和任务边界隔离，不会在多人会话之间串扰。
- [ ] `ADDON_UNAVAILABLE` 或明确的 `UNSUPPORTED_CAPABILITY` 可设置 `fallback_allowed=true`，但回退命令仍需走命令工具自己的审批流程。
- [ ] 参数错误、前置条件失败、限制超出、受保护目标和内部错误不能自动扩大为原始命令执行权限。
- [ ] 玩家明确要求执行原始命令时不被误判为模型自动回退，仍按命令工具风险策略处理。
- [ ] 系统提示只保留施工阶段分组、依赖拆组、内置写前/写后确认和结构化回退四类编排规则。
- [ ] 工具目录和函数描述只说明输入及结果契约，不再重复旧 `mode` 选择、place 风暴或长错误恢复段落。
- [ ] 测试覆盖禁止回退、能力不可用允许独立审批、玩家显式命令、任务切换和多人隔离。
