# 04 — 扩展为一次审批的独立编辑组

**What to build:** 允许 MCBE Chat Agent 在一次 `edit_blocks` 调用中提交同一施工阶段的多个独立编辑，并通过一次预检和一次玩家审批获得可审计、可确认的聚合执行结果。

**Blocked by:** 03 — 用新契约跑通单个方块编辑.

**Status:** ready-for-agent

- [ ] `edits` 接受一个或多个 edit，并允许在同组混合点集、box、不同目标方块和不同 `expect`。
- [ ] 所有 edit 都基于调用开始时的世界状态独立预检；依赖前一 edit 结果的计划不能借助列表顺序通过。
- [ ] 完全相同的重叠目标自动去重；目标状态或前置条件不同的重叠在审批前返回 `CONFLICTING_EDITS`。
- [ ] 同时执行最大编辑数、离散位置数、单个 fill 体积、总目标数、每 tick 工作量和 bridge 字节预算限制。
- [ ] 整组只产生一次预检和一次玩家审批，审批摘要包含编辑数、总目标数、匹配数、跳过数、目标方块计数、非空气替换计数和风险提示。
- [ ] 审批后按稳定 canonical 顺序执行，每项执行前重新检查锁定目标；确定失败后停止尚未开始的后续项。
- [ ] 仅对能够可靠恢复的已写入项执行补偿性回滚；fill 或通信中断导致状态无法确认时返回 `unknown`，不得声称整组原子成功。
- [ ] 聚合结果包含组级状态、总修改数、逐 edit 状态、跳过计数和有界 warnings，使模型不会把 `partial` 或 `unknown` 描述为全部完成。
- [ ] canonical args、审批证据、执行详情和完整 before/after 证据进入工具审计时保持有界并显式携带当前事件 `player_name`。
- [ ] 测试覆盖相同重叠、冲突重叠、同组状态依赖、单次审批、冻结坐标恢复、部分成功和中途失败。
