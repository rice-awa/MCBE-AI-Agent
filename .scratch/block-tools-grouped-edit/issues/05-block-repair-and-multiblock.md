# 05 — 补齐方块修复建议与多格方块安全语义

**What to build:** 让方块 ID、states 和特殊放置错误对 MCBE Chat Agent 保持可解释，并确保门、床、高草等多格方块不会在只验证单格时被错误报告为成功。

**Blocked by:** 04 — 扩展为一次审批的独立编辑组.

**Status:** ready-for-agent

- [ ] 缺失命名空间和大小写差异能够确定性归一化，规范化结果进入审批证据和最终结果。
- [ ] 只有候选唯一时才自动修复明显拼写错误；非唯一情况不得静默选择，并返回最多 3 个候选。
- [ ] 无效 block states 返回结构化 `STATE_INVALID` 和有界建议，不进入审批或执行。
- [ ] `expect` 中的方块 ID 和 states 使用与目标方块相同的校验和修复规则。
- [ ] `expect=any` 仍拒绝覆盖含受保护数据的方块，且整组在审批前失败。
- [ ] 多格方块具有明确的能力声明；支持的类型必须完成整个结构的放置与写后确认。
- [ ] 当前无法完整放置或验证的多格方块返回 `UNSUPPORTED_BLOCK_PLACEMENT` 和 `fallback_allowed=false`，不得只验证其中一格后声称成功。
- [ ] 自动修复、候选建议、受保护目标和多格方块结果均进入有界工具审计记录。
- [ ] 测试至少覆盖唯一拼写修复、歧义候选、非法 states、门或床的完整成功路径或明确不支持路径。
